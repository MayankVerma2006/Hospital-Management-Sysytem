# Hospital Management System 🏥

The **Hospital Management System** is a data-driven project designed to simplify and organize everyday hospital operations. It provides a convenient way for hospitals and healthcare administrators to manage patient records, retrieve important information, and maintain billing details efficiently.

This system allows hospitals to access and manage patient information according to their requirements. It helps organize essential patient details, including Patient ID, Name, Age, Gender, Mobile Number, Medical Information, and Billing Records.

### Key Features & Functionalities

* **Patient Record Management:** Easily store, access, and manage patient information.
* **Patient ID Tracking:** Quickly identify and retrieve individual patient records.
* **Patient Information Search:** Fetch patient details using relevant information such as name or ID.
* **Contact Management:** Maintain patient mobile numbers and other essential details.
* **Billing Management:** Track hospital bills, paid amounts, pending payments, and settlement records.
* **Data Filtering:** Filter patient records according to specific requirements.
* **Record Updates:** Add new patients, update existing information, and delete unnecessary records.
* **Data Analysis:** Organize patient information to make record management more effective.

### Project Objective

The main objective of this project is to demonstrate how Python and Pandas can be used to handle real-world datasets and simplify data management tasks. It focuses on making patient records more organized, accessible, and manageable through a structured approach.

### Technologies Used

* Python
* NumPy
* Pandas
* CSV (Data Storage)

**Note:** This is a learning and practice project demonstrating data management concepts. It is not a production-ready hospital information system.
